# 🎓 Student Management Form

A simple and interactive **Student Management Form** built using **HTML, CSS, and JavaScript**.

This project allows users to enter student details such as **Name, Age, Gender, Course, and E-mail**. The submitted details are dynamically displayed in a table, with an option to delete student records.

## 🚀 Features

- 📝 Add student details
- 👤 Select gender
- 📚 Select course
- 📧 Enter and validate email
- 📊 Display student details in a table
- 🗑️ Delete student records
- ⚡ Dynamic updates using JavaScript
- 📱 Simple and responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📌 Project Purpose

This project was created to practice **JavaScript DOM manipulation, event handling, form validation, and dynamic table creation**.
